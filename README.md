# Gangni Gonit Poribar website

Static website for Gangni Gonit Poribar (গাংনী গণিত পরিবার), a community math club in Gangni, Meherpur.

## Files
- `index.html` – the whole website
- `logo.png` – add the club logo here (square image works best). Until it is added, a "গ" badge is shown.

## Publish on GitHub Pages
1. Create a new public repository on GitHub, e.g. `gangni-gonit-poribar`.
2. Upload `index.html`, `logo.png` and this README (Add file → Upload files → Commit).
3. Go to Settings → Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/gangni-gonit-poribar/`.

To update the site, edit `index.html` on GitHub and commit; the page refreshes automatically.
